UPDATING THE LIVE SITE
1. Extract the ZIP. Copy all files and folders into the ROOT of the
   KameronSchad.github.io repository. Preserve the subfolders.
2. Push/commit on main. GitHub Pages deploys automatically.
3. Reload the website (Ctrl + Shift + R) after deployment.
4. Do not upload this README unless you want it visible in the repo.

EDITING
