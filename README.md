# Kameron Schad - Mechanical Engineering Portfolio

Personal engineering portfolio built for Summer 2027 mechanical design, aerospace hardware, manufacturing, and test internship applications.

## Site

- Home: [kameronschad.github.io](https://kameronschad.github.io/)
- Projects: six individually linked projects
- About: education, experience, skills
- Contact: email, phone, LinkedIn, GitHub, and downloadable resume

## Project highlights

- Rocket Nose Cone Aerodynamics - eight SolidWorks geometries, CFD, wind-tunnel testing, Excel analysis
- Two-Player Claw Machine - original CoreXY-style manual gantry concept, 30+ SolidWorks parts, working physical prototype
- Helmet Light Mount - independent snap-fit design, static FEA, FDM print-orientation iteration, real STEP-derived interactive model
- Confidential Client Design - mechanical CAD and component integration, intentionally excludes client-specific details
- Scene Shop Fabrication - an 18-foot workstation and four mobile worktables
- Computational Methods - MATLAB numerical modeling and data analysis

## Implementation

Static HTML, CSS, and JavaScript hosted with GitHub Pages. The image gallery supports keyboard-accessible dialogs, and the project slideshow respects reduced-motion preferences. The interactive helmet mount uses Google's `<model-viewer>` component and a web-optimized GLB exported from the original STEP geometry.

Changes can be previewed by opening `index.html` locally, or by running a static HTTP server from the repository root. The site does not require a build step.

## Privacy and documentation

Client-owned design files and project-specific confidential information are not published. Performance measurements are labeled as experimental results, simulation outputs, or informal prototype observations; unverified performance claims are avoided.

All content and imagery are from the owner's engineering work or team projects, with team participation credited where applicable.
